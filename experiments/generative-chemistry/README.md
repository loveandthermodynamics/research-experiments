# Reward-free chemical assembly and niche succession

Within Love & Thermodynamics, the larger inquiry asks how the work sustaining life can open possibilities for further life. This construction supplies chemistry in which assembly creates catalytic opportunities and downstream activity returns a small benefit upstream. It makes one generative mechanism inspectable; it does not yet create an additional level of individuality or test whether a collective remains responsible for its participants. See [the physical-study sequence](../physical-individuation/README.md) and [the scope of the claims](../../docs/interpreting-results.md).

The October 20, 2026 model supplies a finite reaction grammar in normalized units. `A + B` assembles `C`; catalytic `C` makes components whose association renews `C`. Byproducts support additional chemical types. There is no added diversity reward, population-selection operator or group-offspring operator driving the ODE.

The reaction grammar, material/energy weights, kinetic capabilities, feed, dilution and possible chemical types are premises. The model therefore provides a conditional constructive example, not a derivation of its chemistry from least action, biological speciation or an open-ended hierarchy of individuals.

[generative-results.json](generative-results.json) preserves the fold threshold, founder-sensitive establishment, limiting and finite-reverse comparisons, byproduct succession, upstream return, controls and material/free-energy identity checks. The finite-reverse example's small upstream return and the optional inhibition comparison are different constructions. Do not replace their stated magnitudes with a universal benefit from adding types.

See [E02](../../CATALOGUE.md#e02) and the [individuation digest](../../docs/topics/individuation-regeneration.md) for the result's place in the later physical program.

## Reproduction

The source declares NumPy, SciPy and Matplotlib dependencies and requires Python 3.11 or later. It writes JSON and a figure beside itself, so run a disposable copy. From that copied folder:

```sh
uv run --no-project generative_model.py
```

For controlled comparisons, use the pinned reference dependencies in [REPRODUCING.md](../../REPRODUCING.md) and record the versions actually used. The [November 7 physical check](../../verification/physical-small-replays-2026-11-07.json) matched all 260 saved numeric values in this suite. Its ordinary-mode execution also retained plotting deprecation warnings; the strict warning-as-error attempt is recorded separately. The original scientific source was not edited to suppress them.

No new stochastic ensemble or biological experiment is implied by that replay. Read [NOTICE.md](../../NOTICE.md) for provenance and reuse status.
