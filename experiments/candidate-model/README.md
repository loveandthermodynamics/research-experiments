# Early candidate models and counterexamples

This October 19, 2026 script contains synthetic calculations used to repair the Entropy Paradox research argument. It does not invoke Hestia, an LLM, a participant, or a physical entropy measurement. Its parameters, welfare criteria and normative objectives are supplied modeling choices.

[candidate-results.json](candidate-results.json) retains seven related families of checks:

| Result field | Question and limit |
| --- | --- |
| `ecological_model` | A regenerative stock/capacity model has a constant-effort sustainable-harvest optimum. A higher-conversion, higher-damage counterexample separates useful throughput from maintained functional stock. The script checks 54 ecological cases and 242 normalized-energy states; the constructed energy budget is not a measurement of an ecosystem. |
| `diversification_model` | A geometric-growth model with correlated shocks and per-channel upkeep has a conditional finite diversity optimum. Its channels and regeneration are supplied. |
| `causal_model` | Eight exact binary policies separate predicting public reports, understanding a protected need, and responding to that need. Prediction accuracy does not determine the direction of care. |
| `conditional_channel_value` | A truthful channel has positive extra value under the declared payoff only when its additional cost satisfies `c < b/4`. This is not a value-of-persons or general funding theorem. |
| `conditional_conscience_model` | Supplied care valuation plus revised other-model information can reverse compliance; the ablations and stronger norm pressure retain counterexamples. A recorded self-estimate is not demonstrated to cause the refusal. |
| `variational_model` | A declared finite-horizon objective can be solved by completing the square. Its chosen optimization problem is distinct from Hamiltonian action or a universal moral potential. A circulation example rejects arbitrary scalar-gradient explanations. |
| `scaling_counterexample` | Shared fixed overhead plus linear cost can imitate a three-quarter power law over a limited range. The asymptotic exponent is one. |

The [catalogue entry E01](../../CATALOGUE.md#e01) preserves each conditional result, adverse comparison and assumption. These calculations help specify later tests; they do not establish the theory's full claims.

## Reproduction

The script uses only the Python standard library. It writes its result beside itself. Use a disposable copy, or run the archive's temporary-copy helper:

```sh
python scripts/replay_quick.py
```

Run that command from the repository root. The [November 7 replay](../../verification/quick-replay-2026-11-07.json) compares all 201 saved leaf values from this family under its declared roundoff tolerances. This is model-output reproduction, not external scientific validation. Read the [reproduction guide](../../REPRODUCING.md) and [reuse notice](../../NOTICE.md).
